Widget Controls
Configure which features appear in the Field Worker and Supervisor mobile apps for each organisation. Disabled widgets are hidden not deleted and can be re-enabled instantly. Use this when an organisation already has existing systems for HR, payroll, time tracking, or safety.
Organisation Enterprise
Organisation-level control: Each organisation on CrewBase can have a different widget configuration. For example, a hospital with an existing SAP HR system can have time tracking and leave requests disabled their workers still see a clean, focused app without those screens. Changes propagate to all devices for that organisation on next app load.
